🏦 Account Management System (Python OOP)

This project demonstrates a simple Object-Oriented Programming (OOP) concept in Python through a basic bank account system.
It includes functionalities such as creating an account, crediting money, debiting money, and checking account balance.

📌 Features: 

Create an account with:
Initial balance
Account number
Debit (withdraw) amount from the account
Credit (deposit) amount to the account
Display current account balance

🧠 Concepts Used:

Concept	Description
Class & Object	Used to create a blueprint (Account) and object (acc1)
Constructor (__init__)	Automatically initializes account balance and number
Instance Variables	balance and account store account-specific data
Methods	credit(), debit(), and get_balance() handle account actions
